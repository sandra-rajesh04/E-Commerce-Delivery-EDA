# E-Commerce-Delivery-EDA
# E-Commerce Delivery & Shipping Data — EDA

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on E-Commerce delivery and shipping data to understand delivery performance, shipping methods, delays, customer ratings and other factors affecting the delivery process.

## 🛠️ Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 🔍 Analysis Performed

- Dataset structure and dimensions
- Data types
- Missing values
- Duplicate records
- Descriptive statistics
- Correlation analysis
- Delivery status analysis
- Shipping method analysis
- Payment method analysis
- Distance vs delivery delay
- Delivery delays by product category

## 📁 Files

- E-Commerce_Delivery_EDA.ipynb — Complete EDA notebook
- E-Commerce_Delivery_EDA_Report.pdf — Project report

## 📚 Dataset

Dataset obtained from Kaggle.
Dataset link : https://www.kaggle.com/datasets/datascikhan/e-commerce-delivery-and-shipping-data-2026
